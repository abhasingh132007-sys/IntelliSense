About the Simulator

Learn by watching real detection logic run

Each scenario generates a realistic packet sequence with Scapy and feeds it straight into the same detection engine used on real network traffic in the Organization Portal — so what you see explained here is exactly how the system would react to a real attack, not a scripted story.
